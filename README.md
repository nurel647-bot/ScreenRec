# ScreenRec — запись экрана для Android

Приложение записывает экран в MP4 (H.265/HEVC или H.264) со звуком системы.
Видео кодируется **аппаратным кодеком** телефона прямо из потока кадров экрана,
поэтому нагрузка на процессор минимальна, а качество задаётся битрейтом.

## Как собрать и установить (один раз)

1. Установи **Android Studio** (бесплатно): https://developer.android.com/studio
2. Запусти Android Studio → **Open** → выбери папку `ScreenRec`.
3. Дождись окончания «Gradle sync» (первый раз скачает нужные файлы, нужен интернет).
4. На телефоне включи **Параметры разработчика** → **Отладка по USB**
   (Настройки → О телефоне → 7 раз нажми «Номер сборки»).
5. Подключи телефон кабелем, разреши отладку.
6. Нажми зелёную кнопку **Run ▶** в Android Studio. Приложение установится и откроется.

Чтобы получить файл APK для установки без компьютера:
**Build → Build Bundle(s) / APK(s) → Build APK(s)**
(файл будет в `app/build/outputs/apk/debug/app-debug.apk`).

## Как пользоваться

1. Выбери разрешение, частоту кадров, кодек и качество (по умолчанию уже стоят хорошие значения).
2. Нажми «Начать запись» → разреши запись экрана (выбери «Весь экран»).
3. Приложение свернётся, запись идёт. Остановить: уведомление «Остановить» или кнопка в приложении.
4. Готовое видео лежит в `Movies/ScreenRec` (видно в Галерее).

## Что важно знать

- Нужен Android 10 или новее (запись системного звука появилась в 10).
- Защищённое содержимое (Netflix, банковские приложения и т. п.) записывается чёрным экраном.
- Некоторые приложения запрещают запись своего звука — в таком видео звука не будет.
- Разрешение не превышает родное разрешение экрана: 4K доступно, только если сам экран 4K.
- Ориентация фиксируется на момент старта записи.
- Если кодек не тянет выбранные параметры, приложение само снижает разрешение или FPS
  (итоговые параметры показаны в уведомлении во время записи).

## Устройство проекта

- `MainActivity.kt` — экран настроек и кнопка записи.
- `RecorderService.kt` — foreground-сервис, держит запись при свёрнутом приложении.
- `ScreenRecorder.kt` — вся логика: захват экрана, видеокодек, звук (AAC), запись MP4.
